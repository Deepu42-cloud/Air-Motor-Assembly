Project Overview

This project is a 3D CAD model of an Air Motor Assembly designed using SolidWorks. The model was created from the provided engineering drawing and consists of multiple mechanical components assembled to demonstrate the working mechanism of an air motor.

Components

The assembly includes:

Base Plate
Mounting Brackets
Motor Block
Cylinder Head
Flywheel
Crankshaft
Connecting Rod
Piston
Crank Pin
Piston Pin
Washers and ISO screws

The drawing identifies 14 component types used in the assembly.

Software Used

SOLIDWORKS
Used for:

Part modeling
3D assembly
Applying mates
Creating the final assembly model
Reviewing the mechanical motion
Working Principle

The air motor uses reciprocating piston motion, which is transferred through the connecting rod and crank mechanism to produce rotary motion of the crankshaft and flywheel.

Key Features
Detailed 3D mechanical assembly
Dimension-based part modeling
Multiple components with mechanical mates
Crank-slider mechanism
Engineering drawing-based design
Final rendered/isometric assembly views
Project Outcome

The completed SolidWorks model provides a clear representation of the construction and mechanical operation of an air motor, while demonstrating practical skills in 3D part modeling, assembly design, and mechanical mechanism development.
